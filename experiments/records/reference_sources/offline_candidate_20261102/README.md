已完成数组的CPU汇总使用模块入口，输出必须是新目录：

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m tools.bank_combine \
  --a-job 154057 --b-job 154058 --output outputs/new_bank_report
```

默认按0–45题来自第一个数组、46–135题来自第二个数组收集；其他范围需显式设置`--split-row`和`--expected-rows`。程序校验全部原始答案指纹，分别生成±60秒和±300秒报告；不复制数据或模型。Slurm入口为`slurm/bank_combine.sbatch`，传入`A_JOB`、`B_JOB`，可设置新目录`OUT_DIR`；只申请1核CPU、512MB，无GPU。
