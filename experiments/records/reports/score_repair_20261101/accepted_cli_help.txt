usage: __main__.py [-h] {prepare,replay,alerts,tool-check,node-demo} ...

Prepare and replay a Bank window without loading any language model.

positional arguments:
  {prepare,replay,alerts,tool-check,node-demo}
    prepare             Split and sort raw Bank data
    replay              Advance one shared clock and populate node inboxes
    alerts              Replay through CPU alert rules; no models
    tool-check          Validate fixed CPU tools and trace latency on replay;
                        no model
    node-demo           Export synthetic node inputs/prompts and test state;
                        no model

options:
  -h, --help            show this help message and exit
