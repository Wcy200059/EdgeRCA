usage: build_trace_view.py [-h] --case CASE [--out OUT]

Build a read-only JSON trace for the EdgeRCA node/coordinator dashboard. Reads
one completed offline case directory (frames, node reports, coordinator
decisions, final answer, evaluation) and writes a compact JSON file. It never
calls a model, reads labels into any model input, or mutates a case.

options:
  -h, --help   show this help message and exit
  --case CASE  completed case directory; repeat for multiple cases
  --out OUT
