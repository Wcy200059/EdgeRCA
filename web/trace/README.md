# EdgeRCA 诊断信息流

这个页面把最新保存的离线诊断拆成可追溯的信息交接：原始记录、程序观测、4B目录决定、节点报告、中央筛选、实际上下文、9B判断、补查、冻结答案和独立评分。

## 打开

直接打开 **[EdgeRCA_trace.html](EdgeRCA_trace.html)**。资源和三个案例全部内嵌，不需要联网或启动模型。直接打开 `index.html` 也会转到这个单文件入口。

新克隆 GitHub 仓库时，先从已发布的实验参考记录恢复案例，再生成单文件：

```bash
python3 -m tools.experiment_records frontend
python3 -m tools.build_standalone_trace
```

这两步不需要原始数据集或模型，不覆盖已有案例目录。完整说明见[实验记录入口](../../experiments/README.md)。

通过本地服务查看多文件版：

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory web/trace
```

打开 `http://127.0.0.1:8765/`；在远程机器运行时可使用端口转发。

## 建议怎样看

1. 顶部选择一个节点和本地观测，点击“查看这项的完整路径”。可以核对原始文件、4B本页编号、报告编号、中央eID、每轮实际载入情况，以及支持、反证或最终引用。
2. 左侧沿实际顺序查看每一步。蓝色是程序，紫色是4B，绿色是9B。每一步明确显示“收到什么、实际做了什么、交出了什么”。
3. 在“程序观测”里核对原始记录条数、不同 KPI 种类和首轮材料条数的等式；查看哪些指标没有进入首轮、程序为何筛选，以及日志、调用和缺失说明的分类。4B看完目录，不表示读过全部原始指标。
4. 在“4B筛选”里切换目录页，对照本页真实输入、原始回复及校验。区分模型明确上报、明确待查，以及未列入这些列表后由程序按协议记成的背景。
5. 在“交给中央”里先看整个节点的材料分流，再看本轮实际载入的条目。载入一条不表示把其余材料汇总成了一条。来自本节点、其他节点和程序全局入口的关联证据分别列出，重复描述同一调用连接的编号可以展开核对。当前选中材料是否载入、是否只出现候选索引片段，另行展示。下方保留18个逻辑节点和每项材料的交接清单。
6. 在“中央”里分别查看全局过滤、程序装配上下文和9B判断。中央候选库、只在索引里出现、本轮明细实际载入、被假设引用是不同状态。过滤前程序原文与过滤9B实际看到的内容可以并排核对。
7. 在“补查”里先看固定工具返回的数值、范围及缺失名称，再看4B实际解释与校验，最后看哪些材料追加、载入或被下一轮引用。提出请求不等于全部执行。
8. 最后才查看独立评分。标准答案与模型输出分开；±60秒和±300秒分别呈现，未被本题评分的字段明确标出。

所有清单都有数量提示，支持搜索和翻页。长文本的完整内容、实际模型消息和保存的JSON可以在详情中查看、复制或下载。图表数据点支持点击和键盘打开原始记录。

## 案例及数据范围

三个案例来自同一份冻结源码 `fc398300…` 的完整实验：

- `outputs/bank_case_154750_1`：Redis02案例；
- `outputs/bank_case_154750_20`：包含全局筛选失败后程序回退的案例；
- `outputs/bank_case_154751_128`：最终判断错误的案例。

这些案例用于检查流程，不代表全量准确率。页面只读实验记录，未修改这些实验的推理代码、预测或评分。

页面完整保存并展示三个案例的节点观测清单、各目录页输入与模型回复、中央各轮输入与输出、全局候选及补查记录。完整原始数据仍在各案例的 `frames/inbox.sqlite`：

- 对所有有同名指标的本地观测提供原始指标序列，每个序列最多嵌入60条；显示总数、已嵌入数和未嵌入数；
- 根据明确的来源编号，每项观测最多嵌入3条原始来源样本，不将节点的无关样本冒充本项原文；
- 其他原始样本可能是保存的片段，会明确标出；
- 长列表或正文在模型输入中若只有概要，页面会保留这个事实，不用存档全文替代模型实际输入；
- 本地库可能包含题目前的参考记录；页面时间与程序事实分别保留，不将它们自动认作模型已读或故障起点。

## 重新导出

导出只使用Python标准库和项目的独立评分函数，不运行模型、不申请GPU、不修改案例。

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m tools.build_trace_view \
  --case outputs/bank_case_154750_1 \
  --case outputs/bank_case_154750_20 \
  --case outputs/bank_case_154751_128 \
  --out web/trace/data
PYTHONDONTWRITEBYTECODE=1 python3 tools/build_standalone_trace.py
```

实现和验证记录位于 `outputs/trace_flow_redesign_20261103/`。新增的数据归属检查在 `tests/test_trace_pipeline.py`。
